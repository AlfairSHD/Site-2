ИНСТРУКЦИЯ ПО РЕДАКТИРОВАНИЮ САЙТА (index.html)
=============================================

Ключевой файл: index.html
Сайт работает без перезагрузки (SPA) и имеет военный интерфейс "планшета".

==================================================
1) ПАРОЛИ РАЗДЕЛОВ
==================================================
Найдите блок:
const SECTION_PASSWORDS = {
  factions: "Nova-17",
  creatures: "Delta-83",
  records: "Copper-42",
  map: "Atlas-55"
};

Как изменить:
1. Поменяйте строку в кавычках у нужного раздела.
2. Сохраните файл.

==================================================
2) ПАРОЛИ КАЖДОЙ ВКЛАДКИ (ВАЖНО)
==================================================
Теперь у каждой вкладки (например, HA-0096 или Faction-001) есть отдельный пароль.

Где это находится:
- В функции makeItems(sectionKey)
- Поле: itemPassword

Фрагмент:
itemPassword: TAB_PASSWORD_DEFAULTS[i % TAB_PASSWORD_DEFAULTS.length],

Как сделать уникальные пароли вручную:
1. После генерации DATA замените нужные itemPassword в конкретных объектах.
2. Или измените логику makeItems, чтобы назначать индивидуальные пароли по вашему правилу.

==================================================
3) НАЗВАНИЯ ВКЛАДОК И КОЛИЧЕСТВО
==================================================
Найдите объект SECTION_META:
- factions: prefix "Faction-", count 10, pad 3
- creatures: prefix "HA-", count 40, pad 4
- records: prefix "Record-", count 100, pad 3

Как изменить:
- count: количество вкладок
- prefix: начало названия
- pad: количество цифр (например 4 = 0001)

Пример:
Чтобы было 12 фракций, поменяйте count: 10 -> 12

==================================================
4) КАК ИЗМЕНИТЬ ТЕКСТ ВО ВКЛАДКЕ
==================================================
Внутри каждого элемента есть поле:
paragraphs: ["...", "...", "..."]

По умолчанию уже вставлены явные заглушки:
- "ТЕКСТ ЗДЕСЬ — ЗАМЕНИ"
- "ОПИСАНИЕ СУЩЕСТВА — ЗАМЕНИ"
- "ИСТОРИЯ ФРАКЦИИ — ЗАМЕНИ"
- и другие аналогичные подписи.

Комментарии в коде:
- // ${name} текст
- <!-- Здесь вставляйте текст -->

Пример:
Чтобы изменить текст Faction-003:
1. Откройте index.html.
2. Найдите объект Faction-003 в DATA.factions.
3. Измените тексты внутри массива paragraphs.

==================================================
5) КАК ЗАМЕНИТЬ ИЗОБРАЖЕНИЯ И ПОДПИСИ
==================================================
У вкладки есть массив:
images: [
  { src: "...", caption: "..." },
  ...
]

Комментарии в коде:
- // ${name} изображения
- <!-- Здесь вставляйте изображения -->
- <!-- Вставьте фото сюда -->

По умолчанию везде уже стоят подписи:
- "ВСТАВЬ ИЗОБРАЖЕНИЕ СЮДА"
- "ГАЛЕРЕЯ — ЗАМЕНИ ФОТО"

Как заменить:
1. Поставьте в src путь к своей картинке или URL.
2. Подпись измените в caption.

Пример:
{ src: "img/ha-0096-main.jpg", caption: "HA-0096: основной профиль" }

==================================================
6) КАК ДОБАВИТЬ НОВОЕ ИЗОБРАЖЕНИЕ В ГАЛЕРЕЮ
==================================================
1. Найдите нужную вкладку.
2. В массив images добавьте новый объект:
   { src: "img/new-photo.jpg", caption: "Новая подпись" }
3. Сохраните файл — миниатюра появится автоматически.

==================================================
7) КАРТА МИРА
==================================================
Ищите функцию renderMapSection() и комментарии:
- <!-- Карта Мира текст -->
- <!-- Здесь вставляйте текст -->
- <!-- Карта Мира изображение -->
- <!-- Здесь вставляйте изображения -->

Чтобы вставить свою карту:
1. В блок gallery-preview вставьте тег <img src="..." alt="Карта" />.
2. При необходимости подключите JS-карту (Leaflet и т.д.).

==================================================
8) НАВИГАЦИЯ BACK
==================================================
Схема:
Главная -> Раздел -> Вкладка -> Пароль вкладки -> Контент

Кнопка BACK всегда возвращает на предыдущий экран.
Основа логики: historyStack, pushAndRender(), goBack().

==================================================
9) БЫСТРЫЕ СЦЕНАРИИ
==================================================
A) Изменить фото для HA-0096:
1. Найдите DATA.creatures.
2. Найдите объект name: "HA-0096".
3. В images замените src/caption.

B) Сменить пароль для Faction-001:
1. Найдите объект name: "Faction-001".
2. Поменяйте itemPassword на новый.

B2) Изменить текст в HA-0096:
1. Найдите объект name: "HA-0096".
2. Измените строки в paragraphs на свой текст.

C) Добавить Record-101:
1. В SECTION_META.records измените count: 100 -> 101.
2. Сохраните файл.

==================================================
10) ЧТО БЕЗОПАСНЕЕ НЕ ТРОГАТЬ НОВИЧКУ
==================================================
Лучше не менять:
- функции pushAndRender, goBack
- структуру renderMainShell
- обработчики checkSectionPassword / checkItemPassword

Меняйте только:
- SECTION_PASSWORDS
- SECTION_META (prefix/count/pad)
- paragraphs, itemPassword, images у вкладок
